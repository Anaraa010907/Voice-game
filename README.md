# Voice Game

Dark navy and gold glassmorphism UI prototype for a multiplayer party gaming platform.

## Included in this first UI pass

- Home dashboard with Monopoly and Spyfall feature cards
- Interactive Spyfall room with speaking indicator, player list, microphone state, and invite actions
- Monopoly board room with player balances, properties, and dice area
- Profile customization with nickname and animal avatar picker
- Shop with category filtering, purchase feedback, and live coin balance
- Shared navigation between all screens
- Landscape-first layout for tablet and desktop browsers

## Run locally

```bash
npm install
npm run dev
```

Production check:

```bash
npm run build
```
